# Reglas de Selección y Uso de Skills

## Regla Imprescindible e Irrompible

Antes de cada tarea, identifica su tipo y elige las skills disponibles más específicas para ella. Lee sus SKILL.md y sigue sus instrucciones. Combina skills solo cuando aporten algo distinto; no leas ni apliques todas indiscriminadamente. Usa una skill de revisión o QA cuando la tarea incluya comprobar el resultado. Al terminar, indica brevemente qué skills aplicaste y por qué. No afirmes haber usado una skill si no leíste sus instrucciones.
