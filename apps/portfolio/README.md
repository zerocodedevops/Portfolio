# 🎨 ZeroCode Portfolio App

![React](https://img.shields.io/badge/react-%2320232a.svg?style=for-the-badge&logo=react&logoColor=%2361DAFB)
![Framer Motion](https://img.shields.io/badge/Framer_Motion-black?style=for-the-badge&logo=framer&logoColor=blue)

La **Aplicación Principal** que actúa como punto de encuentro unificado de cara al público. Orquesta la presentación de todos los sub-proyectos y sirve como carta de presentación inmersiva.

## 🌟 Características Destacadas

- **Animaciones Fluidas:** Impulsado por `framer-motion` para una experiencia de usuario premium.
- **Multilenguaje (i18n):** Soporte de internacionalización a través de `react-i18next`.
- **Integración Backend:** Conexión con _Supabase_ y auth administrado por _Firebase_.
- **Rendimiento Extremo:** Bundling altamente optimizado en Vite, segmentando librerías pesadas en chunks.

## 🚀 Despliegue Local

El portfolio está diseñado para ejecutarse en el puerto base:

```bash
# Desde la raíz del monorepo
npm run dev
# O directamente:
cd apps/portfolio && npm run dev
```
