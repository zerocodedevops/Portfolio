Un entorno de comercio electrónico de modelo base, limpio y preparado para escalar.

## 🌟 Arquitectura

- Construido puramente en **React** con bundler **Vite**.
- Estilizado de raíz utilizando utilidades atómicas de **Tailwind CSS**.
- Preparaciones listas para el alojamiento en sistemas Serverless (`Firebase`).

## 🚀 Despliegue Local

```bash
cd apps/ecommerce
npm run dev
```
