Software avanzado para la gestión logística de despachos, control de entregas y administración de vehículos.

## 📦 Arquitectura

- **Formularios Estrictos Independientes:** Implementación centralizada de `@hookform/resolvers` y `zod` para predecir y repeler errores de usuario antes de procesar un envío.
- **Componentes Accessibles:** Interfaz basada en `@headlessui/react` garantizando accesibilidad total.
- **Iconografía Unificada:** Aprovechamiento global de `@heroicons/react`.

## 🚀 Despliegue Local

```bash
cd apps/shipping-service
npm run dev
```
