Frontend avanzado y robusto de comercio electrónico del ecosistema ZeroCode. Diseñado para manejar catálogos complejos, estados de carrito centralizados y pasarelas de pago.

## ✨ Features

- **Gestión de Estado Centralizada:** Implementación completa y estricta de `Redux Toolkit` para la persistencia del carrito, estados de autenticación y navegación.
- **Pasarela de Pagos Global:** Checkout inmersivo y seguro mediante `@stripe/react-stripe-js`.
- **Diseño Responsive Moderno:** Componentes base construidos sobre TailwindCSS e integraciones headless UI (`@radix-ui`).

## 🚀 Despliegue Local

El servidor Vite arrancará en modo de desarrollo integrado:

```bash
cd apps/ecommerce-shop
npm run dev
```
