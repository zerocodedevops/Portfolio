# 💇‍♀️ ZeroVanity (Salón de Belleza)

![React](https://img.shields.io/badge/react-%2320232a.svg?style=for-the-badge&logo=react&logoColor=%2361DAFB)
![Day.js](https://img.shields.io/badge/Day.js-FF5C4D?style=for-the-badge&logo=day.js&logoColor=white)

Demo visual para un salón de belleza, integrada en el portfolio de ZeroCode. Todas las reservas, citas y cambios administrativos son simulados con datos ficticios en memoria; no hay autenticación, persistencia ni conexión a bases de datos.

## 📅 Componentes Core

- **Recorrido de reserva:** Selección de servicios, profesional, fecha y hora con confirmación simulada.
- **Panel de demostración:** Las acciones solo cambian el estado local de la sesión y usan datos de ejemplo.

## 🚀 Despliegue Local

```bash
cd apps/zerovanity
npm run dev
```
