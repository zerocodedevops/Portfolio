# 🪙 Crypto Live Tracker

![React](https://img.shields.io/badge/react-%2320232a.svg?style=for-the-badge&logo=react&logoColor=%2361DAFB)
![WebSockets](https://img.shields.io/badge/WebSockets-black?style=for-the-badge&logo=socket.io&logoColor=white)

Una aplicación financiera dinámica construida para rastrear cotizaciones de criptomonedas en tiempo real.

## ⚡ Core Tech

- **Real-Time Data Streams:** Consumo de datos crudos mediante conexiones WebSockets ultrarrápidas con agregadores del mercado (Binance/CoinGecko).
- **Interactive Charts:** Renderizado de velas y gráficos de línea para análisis técnico.
- **Micro-Animaciones:** Transiciones verdes/rojas al inyectar nuevos ticks de precios para UX superior.

## 🚀 Desarrollo

```bash
cd apps/crypto
npm run dev
```
