# 🏗️ Home Renovation (ZeroChaos)

![React Router](https://img.shields.io/badge/React_Router-CA4245?style=for-the-badge&logo=react-router&logoColor=white)
![React](https://img.shields.io/badge/react-%2320232a.svg?style=for-the-badge&logo=react&logoColor=%2361DAFB)

Solución integral B2B y B2C para la planificación, trazado y ejecución en tiempo real de proyectos de reforma del hogar o construcción.

## 🛠️ Especificaciones

- **Enrutamiento Modernizado:** Adopta integralmente `react-router` v7 y resoluciones de layout fluidas, distanciándose del routing de Remix.
- **Flujos MultiPaso:** Componentes diseñados para permitir al usuario construir su presupuesto de reforma dinámicamente.
- **Estilos Ultra Rápidos:** Construido en su totalidad adoptando la metodología Tailwind.

## 🚀 Despliegue Local

```bash
cd apps/home-renovation
npm run dev
```
