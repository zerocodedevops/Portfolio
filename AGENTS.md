# NORMA SUPREMA: Protocolo Obligatorio de Selección y Uso de Skills

Esta es la directriz de máxima prioridad para cualquier tarea, en cualquier proyecto y bajo cualquier circunstancia.

## Protocolo Obligatorio (Paso 0 - Antes de ejecutar nada)

1. **Consulta Previa Obligatoria de Skills:**
   - Antes de escribir una sola línea de código, ejecutar comandos de modificación o tomar decisiones de implementación, debes consultar el catálogo de skills disponibles.
   - Identifica explícitamente qué skill o combinación de skills (una o varias) es la más adecuada para la tarea en curso.

2. **Lectura de Instrucciones:**
   - Lee el archivo `SKILL.md` de cada skill seleccionada con `view_file` para seguir sus directrices exactas y mejores prácticas.
   - No apliques skills indiscriminadamente ni afirmes haber usado una skill sin haber consultado sus instrucciones.

3. **Verificación y QA:**
   - Cuando la tarea implique generar cambios o verificar código, selecciona e incorpora obligatoriamente una skill de revisión/QA (por ejemplo, `verification-loop`, `tdd-workflow`, etc.).

4. **Trazabilidad y Cierre:**
   - Al finalizar la respuesta, indica brevemente qué skills fueron seleccionadas, por qué se escogieron y cómo se aplicaron.
