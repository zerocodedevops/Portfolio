# 🚀 ZeroCode Portfolio

Monorepo con 7 aplicaciones de demostración de desarrollo full-stack.

## 📦 Aplicaciones

| Nombre          | Stack                  | Descripción                |
| --------------- | ---------------------- | -------------------------- |
| **crypto**      | React + WebSocket      | Dashboard cripto real-time |
| **devops-shop** | React + Redux + Stripe | E-commerce                 |
| **analytics**   | React + Recharts       | Dashboard analítico        |
| **zerodelay**   | React + Vite           | Sistema de logística       |
| **zero-chaos**  | React + Vite           | Plataforma de reformas     |
| **zerovanity**  | React + Supabase       | Salón de belleza           |
| **ecommerce**   | React                  | E-commerce generic         |
| **portfolio**   | React + Vite           | Portfolio principal        |

## 🚀 Quick Start

```bash
npm install
npm run dev          # Inicia portfolio + todos los apps (requiere turbo)
npm run build        # Build todo (requiere turbo)
npm run lint         # Chequea calidad
```
